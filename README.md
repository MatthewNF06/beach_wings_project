# 🌴 Beach Wings Network **O 1º Marketplace Exclusivo da Orla** Bem-vindo ao repositório do **Beach Wings Network**, uma plataforma web (SaaS) desenvolvida para digitalizar e otimizar as vendas diretas de quiosques litorâneos. Este projeto nasceu para resolver uma dor real do mercado gastronômico: a altíssima dependência de aplicativos de entrega terceirizados (que cobram até 27% de taxa) e a dificuldade de logística de atendimento diretamente na areia. --- ## 🎯 O Problema e a Solução **O Problema:** Lojistas à beira-mar sofrem com taxas abusivas dos grandes marketplaces, enquanto os banhistas enfrentam filas, demora no atendimento e dificuldades de pagamento debaixo de sol. **A Solução (Beach Wings):** Uma plataforma web responsiva e centralizada onde o cliente ("banhista") pode visualizar os quiosques abertos na sua região, montar um carrinho unificado (pedindo itens de locais diferentes simultaneamente), realizar reservas de mesas e acompanhar o seu histórico de pedidos. Tudo isto com uma interface moderna e taxas de comissão muito mais justas para o lojista. --- ## 📊 Modelo de Negócios e Viabilidade O sistema foi arquitetado para operar no modelo **SaaS (Software as a Service)**, focando em duas pontas: * **B2B (Lojistas):** Monetização através de uma **Taxa de Adesão** (R$ 800,00 para setup) e uma **Mensalidade Fixa** (R$ 149,90) aliada a uma comissão agressiva de apenas **2% por pedido online**. * **B2C (Banhistas):** Utilização gratuita, focada na conveniência, agilidade e unificação da orla. > *Nota de Mercado (2026): O desenvolvimento de uma plataforma com esta arquitetura sob medida tem um custo estimado entre R$ 15.000 e R$ 25.000. O licenciamento B2B dilui este custo, gerando alta lucratividade.* --- ## 🏗️ Arquitetura do Software (MVC) O projeto foi construído utilizando o padrão de arquitetura de software **MVC (Model-View-Controller)**, garantindo separação de responsabilidades, alta manutenibilidade e escalabilidade. * **Ponto de Entrada Único:** Todas as requisições passam pelo `index.php` (Roteador Frontal). * **Views (Interface):** Totalmente limpas de lógicas complexas. Utilizam o princípio **DRY (Don't Repeat Yourself)** através de inclusão dinâmica de `header` e `footer`. * **Controllers (Orquestradores):** Interceptam a ação da URL, acionam as validações nos Models, controlam as variáveis de Sessão (Carrinho e Alertas) e decidem qual View apresentar. * **Models (O Cérebro):** Centralizam as regras de negócio e detêm o monopólio da comunicação com o banco de dados. --- ## 💾 Banco de Dados Relacional (MySQL) O sistema opera com um banco de dados **MySQL** robusto, gerido nativamente pelo PHP através da biblioteca **PDO (PHP Data Objects)**. ### Estrutura e Segurança: 1. **Relacionamentos 1:N (Foreign Keys):** A tabela mestre é a de `Quiosques`. A plataforma sabe sempre a qual estabelecimento pertencem os `Produtos`, `Reservas` e `Itens_Pedido`. 2. **Prevenção de SQL Injection:** Utilização estrita de **Prepared Statements** e vinculação de parâmetros (`bindParam` / `execute([$array])`) em todas as interações de *CRUD*. 3. **Criptografia:** Senhas de usuários armazenadas no banco de dados com hashes seguros via `password_hash()` (Algoritmo BCRYPT). ### Transações ACID no Checkout: Para garantir que a lógica do "Carrinho Inteligente" não corrompa dados em caso de falhas de conexão, a finalização do pedido utiliza transações do banco de dados (`$conn->beginTransaction()`). * **O Pedido é fracionado:** O cabeçalho grava na tabela `Pedidos` (total e cliente), e cada prato grava na tabela `Itens_Pedido`. * **Garantia:** Se um erro ocorrer a meio da inserção, é executado um `$conn->rollBack()`. Se for bem-sucedido, o `$conn->commit()` regista tudo. --- ## 🎨 UI/UX e Tecnologias A interface foi desenhada para a melhor experiência "mobile-first", respeitando as normas de Usabilidade. * **Framework Base:** **Bootstrap 5**, complementado por CSS customizado. * **Identidade Visual (Dark Mode Imersivo):** Paleta inspirada na costa (Azul Oceano Profundo, Amarelo Areia e Laranja Pôr do Sol), garantindo alto contraste e modernidade. * **Feedback Dinâmico:** Utilização intensiva de variáveis de Sessão (`$_SESSION`) para exibir Alertas Visuais (Verde para sucesso, Vermelho para erro) sem quebrar o fluxo de navegação do utilizador. * **Carrinho Inteligente:** Botões otimizados para manter o utilizador no fluxo de compras e atualizações do número de itens refletidas imediatamente no Navbar (Header). --- ## 🚀 Requisitos e Execução (MosCoW) ### Entregues (Must Have / Should Have): ✅ Arquitetura MVC funcional e Roteamento central. ✅ CRUD Completo em MySQL (PDO). ✅ Interface Dark Mode Responsiva (Bootstrap). ✅ Carrinho de compras robusto mantido em Sessão. ✅ Transações de BD (Commit/RollBack) e Prepared Statements. ✅ Criptografia BCRYPT. ### Visão de Futuro (Could Have): ⏳ Integração com APIs de pagamento em tempo real (Pix / Gateway de Cartão). ⏳ Painel Administrativo de "Cozinha" (Backoffice Lojista). --- *Projeto desenvolvido por Matheus Abreu de Campos para a disciplina de Desenvolvimento Web.*
